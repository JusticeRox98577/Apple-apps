Ocean Live for Android

Open this folder in Android Studio (File, Open). Let it sync, plug in your Android phone with USB debugging on, and press Run.

To share it as an installable file, build the APK with Build, Build Bundle(s) / APK(s), Build APK(s). The ready made debug file is in the apk folder next to this one.

Phone setup
1. Allow Bluetooth, Location and Notifications when asked. Choose "Allow all the time" for Location if Android offers it.
2. Open Settings in the app, enter your ABRP API key and Generic token, and pick your Ocean model.
3. Press Start, enter the charge shown on the car screen, and it connects to the vLinker and starts sending.
4. In Android settings for the app, set Battery to Unrestricted so the system never pauses it while you drive.

For Google Play you need a signed release bundle (Build, Generate Signed App Bundle) and a $25 one time developer account.
